Build a metrics dashboard page for a sales analytics product, using the components in this repo.

Put it in one file: `src/dashboard/Dashboard.tsx`, exporting a React component called `Dashboard`.

The dashboard shows:
- Four headline numbers: revenue, orders, conversion rate and churn, each with its change vs. last month
- A chart of revenue by week, with this year and last year
- A table of the top five regions by revenue
- Filters for region and plan
- What the page shows while its data is loading, and if the query fails

Use made-up data. Write the whole file in one pass. Don't run any commands, and don't check or fix type errors afterwards.
